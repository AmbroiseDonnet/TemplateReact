# TemplateReact

Un template personnel pour créer rapidement une **SPA React** avec :

- **React Router** pour la navigation
- Un **Design System** intégré
- Une base prête à être adaptée à de nouveaux projets

---

## 🎯 Objectif

Ce dépôt sert de point de départ pour éviter de recréer la même structure à chaque nouveau projet React.

---

## 🧱 Ce que contient le template

- Structure SPA claire
- Routage déjà pensé pour évoluer facilement
- Fondations UI cohérentes via le Design System

---

## 🚀 Démarrage (à adapter selon ton setup)

```bash
# installer les dépendances
npm install

# lancer le projet en développement
npm run dev

# générer la version de production
npm run build
```

> Si tu utilises un autre gestionnaire de paquets, adapte simplement les commandes (`yarn`, `pnpm`, etc.).

---

## 🛠️ Personnalisation rapide

1. Renommer le projet
2. Adapter les routes principales
3. Ajuster les tokens/styles du Design System
4. Ajouter tes pages métier
